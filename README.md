# Mulan — A little Penang. A lot of heart.

An independent website redesign concept for Mulan Malaysian Café & Restaurant in Birkenhead, Auckland. Designed as a client presentation, with a warm editorial identity, expressive typography, real restaurant photography and thoughtful mobile layouts.

## Client preview

https://shankarappan.github.io/mulan-restaurant-concept/

## Features

- Responsive desktop, tablet and phone layouts
- Three menu collections with links to Mulan's published menus
- Keyboard-accessible menu tabs and mobile navigation
- Native photo lightbox with Escape support
- Reservations, takeaway, gift vouchers, catering, phone and map links
- Reduced-motion support and semantic page structure
- Plain HTML, CSS and JavaScript; no build step or runtime dependencies

## Run locally

```sh
python3 -m http.server 4173
```

Open http://localhost:4173. GitHub Pages serves the root directory from the main branch.

## Content and assets

Restaurant information, family background, suppliers, menu links and photographs are sourced from [Mulan's current website](https://mulan.co.nz/) and [gallery](https://mulan.co.nz/gallery/), reviewed 8 October 2026. Photography and restaurant branding belong to their respective owners; they are included for the Mulan client concept. Italiana and DM Sans are served by Google Fonts. Original editorial copy and visual direction were created for this concept.

This is a presentation concept, not Mulan's official website. Booking and ordering actions lead to the restaurant's existing services. No booking, order or payment is submitted by the prototype. Opening hours differ across the current site, so the concept links visitors to current reservation information instead of publishing an unverified schedule.
